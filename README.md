# Muse Project Outline

## Overview
Muse is a browser-based audio sharing experience. Everything happens in the web app, with audio files handled locally in the browser instead of depending on a native app or desktop install.

## Project Goals
- Build a browser-first audio sharing experience with a simple, focused flow.
- Let users open a directory from their own filesystem and work with the audio files inside it.
- Keep file handling local and lightweight in the browser.
- Preserve a responsive, accessible UI across desktop and mobile.

## Current Flow
- Users open a directory from their local filesystem through the browser.
- The app reads and organizes the audio files available in that directory.
- Playback and metadata handling stay inside the browser.

## Future Work
- WebRTC is still in progress and may be added later.
- Zip import is planned for the future.
- We are not including zip support in the current version.
