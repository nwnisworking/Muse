# Muse Project Outline

## Overview
Muse is a peer-to-peer audio sharing project that uses WebRTC for direct transfers and supports MP3 processing in the browser. Audio files are stored in IndexedDB for fast local access.

## Project Goals
- Build a peer-to-peer audio sharing web app focused on direct listener-to-listener exchange.
- Provide a lightweight onboarding flow (email sign-up and sign-in) with clear UX.
- Support local-first audio handling in the browser (including IndexedDB-based storage/caching).
- Establish reliable peer connection workflows for sharing audio metadata and playback resources.
- Keep the interface responsive and accessible across desktop and mobile.

## Key Features
- Peer-to-peer sharing sessions so users can exchange tracks directly without centralized upload dependency.
- Email capture and account entry points (sign up and sign in) on the landing experience.
- Browser-side audio persistence via IndexedDB for faster repeat access and offline-friendly behavior.
- MP3-focused parsing and metadata handling for track details, organization, and playback context.
- Responsive landing UI with clear call-to-action flow and mobile-safe layout breakpoints.
